# RunPulse 비전 (단일 원본)

> 변경은 사용자 승인 후에만. 제안은 `vision-proposals/` 에.

[제품 본질] RunPulse 는 '개인 러닝 인텔리전스 플랫폼'이다. 여러 서비스(Garmin·Strava·Intervals·Runalyze)에 흩어진 러너의 데이터를 한곳에 모아 소유하고, 계산 근거를 투명하게 보여 주며, 오늘 무엇을 해야 하는지 맥락 있게 안내한다.
사용자: 4개 앱 탭을 오가던 러너. 데이터 과학자가 아니다. '왜 쉬어야 하는가'의 근거 수치와 한국어 설명을 원한다.
원칙(우선순위 순): 1.Evidence-First(결론마다 근거 수치) 2.Drillable Everything(모든 수치는 출처까지 파고들 수 있다) 3.Provider Transparency(어느 서비스 값인지 보인다) 4.Intent-Centered IA(탭이 아니라 의도 중심) 5.Quiet Data(조용하고 읽기 쉬운 데이터) 6.One Finger Reach(모바일 한 손 입력) 7.State-Bound Plan(플랜은 현재 상태에 묶인다) 8.Data Ownership(내 데이터는 내 것).
되지 않을 것: 소셜 앱, 라이브 GPS 추적, 정적 PDF 플랜, 클라우드 종속.
판단 기준: 사소한 결함이라도 위 원칙(근거 누락·출처 불명·이해 불가한 수치)을 훼손하면 우선순위를 높이고, 본질과 무관한 장식·기능 추가 제안은 하지 않는다.
