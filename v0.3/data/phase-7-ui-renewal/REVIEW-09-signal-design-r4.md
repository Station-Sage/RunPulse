## 1. 문제 정의

r3의 작업구간 W는 "연속 랩 블록(≥2km·≥8분)의 평균 페이스를 그 지속시간의 레이스로 본" 값이었다. 두 가지가 틀렸다.
1. **1km 이하 반복·휴식 세트를 버린다.** 이 러너의 품질 세션 대부분(1000m×5, 400m×6, nsm 3.5분×9, 크루즈 1km×4)이 여기에 해당한다 → 인터벌 위주 주간의 훈련 반응이 빠진다.
2. **연속 블록도 편향된다.** 템포는 레이스가 아니라 T 강도(≈60분 레이스 강도)로 뛴다. 레이스 공식에 실제 지속시간(13~20분)을 넣으면 체력을 과소 추정한다. 측정: 연속 블록 n=23, 가장 가까운 전력 대회(±42일) 대비 **중앙 −2.47 VDOT, SD 1.76** [사실]. r3의 비대칭 결합(`W<A면 A+0.25(W−A)`)은 이 편향을 사후에 누른 장치였다.

## 3. 세트 → VDOT 환산 (휴식 보정)

### 3-1. 세트 추출 (기기 불필요)
- 랩(GAP 우선) → 블록 라벨(r3 `label_blocks`) → 작업 블록에 붙은 짧은 조각(오토랩 꼬리)은 작업으로 합침 → bout(연속 작업 + 직후 휴식 길이·속도).
- 구조: 반복 수 n, 반복 중앙 길이, 총 작업 시간, 작업 평균 속도, **ρ = 휴식/작업**(마지막 bout 제외). 휴식 속도 ≥ 작업 속도×0.75(플로트)는 휴식으로 세지 않는다 (c).
- **품질 조건**: 작업 평균 속도 ≥ 직전 90일 이지 기준 속도 × **1.18** (c). 이유: 오토랩 이지런의 약간 빠른 1km 랩이 "인터벌"로 잡히는 오탐(잔차 −6~−12 VDOT) 제거. HR 기준(평균 HR/LTHR ≥ 0.9)은 SD를 줄이지 못했다(1.82 vs 1.90). 민감도: 1.12 → 대회 D-0 MAE 2.86%, 1.18 → 1.63%, 1.25 → 1.84%.

### 3-2. 등가 지속시간 t_eq (Daniels 앵커 + 로그 보간)

| 구조 | 구간 | t_eq | 근거 |
|---|---|---|---|
| 연속 8~40분, 또는 ρ ≤ 0.2 | T | 60분 | (a) 템포·크루즈 = T 강도, 크루즈 처방 휴식 5분당 1분(ρ=0.2) [가정: 원문 확인] |
| ρ ≥ 1.0 | I | 11.03분 | (a) I 처방 휴식 = 작업 이하 [가정: 원문 확인] |
| 0.2 < ρ < 1.0 | T~I | exp(ln60 + (ln11.03−ln60)·ln(ρ/0.2)/ln5) | (c) 보간 형태. 아래 데이터 확인 |
| 반복 ≤150초, ρ ≥ 1.5 | R | 1마일 레이스 | (a/가정) |
| 연속 ≥ 40분 | M | 마라톤 레이스 | (a) |

VDOT_set = VO2(v_work) / %VO2max(t_eq). 라벨 경계 T/I = ρ 0.447(두 처방의 기하 중간).

| 레이스 공식(실제 지속시간, r3 W) | −2.47 / 1.76 (n=23) | – | – | – |
| 이산 구간(T=0.888, I=1.0) | +0.22 / 1.80 | **−2.11** / 1.53 | +0.83 ± 0.34 | −0.78 ± 0.22 |

- 보간 후 휴식 비율·반복 길이에 남는 구조가 없다 → 휴식 보정 형태가 데이터와 맞는다. 편향 보정 상수가 필요 없다(학습 상수 0개).
- 추가 공변량(LOO RMSE): 없음 1.93, 총 작업시간 보정 1.90, 상수 편향 1.95 → **채택 안 함**. fade(n=14) 기울기 −0.07±0.22 → 무관.
- **기온**: 세트를 heat_model로 15℃ 정규화하면 잔차 SD가 커진다(φ=0 1.90, 0.5 1.92, 1.0 2.21). 칼만 전 관측 우도도 세트 φ=0이 최선(−135.9 vs φ=1 −151.3), 대회는 φ=1(−135.9) ≥ φ=0(−138.5). [판단] 훈련은 처방 페이스로 뛰고 더위 비용은 HR로 낸다, 대회는 전력이라 더위가 기록을 늦춘다. → **세트는 기온 정규화 안 함, 대회만 정규화**(r3의 "W 예외"를 일반 규칙으로).

## 4. 거리별 신호 매핑 (가중에서 자동으로 나온다)

각 관측 i는 고유 거리 d_i(대회 = 거리, 세트 = v·t_eq ≈ T 13km·I 3km, H = 60분 거리)를 갖는다. 목표 거리 d로 옮길 때
`y_i→d = VDOT(d, Daniels(y_i, d)·(d/d_i)^(k−1.06))`, 추가 분산 `(k_sd·|ln(d/d_i)| / e_d)²`(e_d = 1 VDOT당 ln 시간 변화).

| 목표 | 가장 무겁게 들어가는 관측 | 가볍게 들어가는 관측 |
|---|---|---|
| 5K | I·R 세트, 5K·10K 대회 | 하프 대회, M |
| 10K | 10K 대회, T·I 세트 | M |
| 하프 | 하프 대회, T 크루즈·연속 템포, H | R |
| 마라톤 | 하프 대회, M 구간, T 세트, Tanda(볼륨) | R, I |

별도 거리별 가중 표(휴리스틱)를 두지 않는다. 외삽 불확실성 = 개인 지구력 지수 k의 사후 SD — 추가 상수 없음.

## 5. 결합과 세션별 가중 (추가 요구 B)

**로컬 레벨 칼만 필터**: 상태 x = 레이스 능력(VDOT, 15℃ 등가), 랜덤워크 하루 분산 q. 관측 가중은 사실상
`w_i ∝ 1 / (r_i × m_i + q·경과일_i + 외삽분산_i(d))` — (i) 품질 m_i, (ii) 시간 거리, (iii) 유형–거리 관련성이 한 식에 들어간다.

| 요소 | 형태 | 값 | 등급 |
|---|---|---|---|
| 대회 관측 SD | r = σ² | 1.0 VDOT (95% 0.5~2.0) | (b) 전 관측 MLE |
| 세트 관측 SD | | 1.75 (1.5~2.0) | (b) MLE, 잔차 SD 1.90과 일치 |
| H 관측 SD | | 1.25 | (b) D-0 잔차 1.58² − 1.0² (n=8) |
| 시간(과정 분산) q | 대회 가중 반감 σ²/q | **0.01/일** → 대회 100일, 세트 306일 | (c) 전 관측 MLE 0.05(0.02~0.12)는 세트 오차 자기상관으로 과대(2상태 모형: 세트 편향 τ≈1.0, 반감 52일, LR 1.5 비유의), 대회 조건부 우도는 0.002 최빈이나 0.001~0.1 식별 불가. 민감도 R4-3 |
| r3 감쇠 0.08/주 | 폐기 | q가 시간 감쇠를 대신(평균 이동 없이 분산 증가) | – |
| 품질: 심박 도달도(T1) | m = exp(0.36·max(0, 0.92 − 후반 최대HR/HRmax)·100) | 기울기 0.36±0.20 (t=1.8) | (b, 약함) |
| 품질: 더위 | 중앙값 환원 안 함, 문헌·개인 heat_model은 **약한 사전·재검정 대기** | 로그-분산 0.07±0.07 (t=1.0), 세트 15℃ 환원 시 편향 −1.4~−1.6% | **미검출 ≠ 부재**: 세트의 하한 편향과 섞여 식별 안 됨. Open-Meteo 외기 채운 뒤 재검정(REVIEW-07 §R4-8(1), U-14) |
| 품질: 휴식 보정 신뢰도(보간 위치) | ln ρ 구간 중앙에서 SD +0.75 VDOT (분산 가산) | 0.35±0.69, 백테스트 ±0.02 | (c) 약한 사전 — 채택 후보(분산만 넓힘) |
| 품질: fade | 후반 속도 저하 2% → 분산 2배 | 기울기 0.0, 백테스트 −0.04/+0.06 | (c) 약한 사전 — 채택 후보. 지속 가능 반복만 쓰는 안은 U-15 |
| 대회·세트 비대칭 | 현재 상태보다 낮은 관측만 분산 ×4 (대회 = 상한 증거, 세트 = 하한 증거) | 백테스트 중립 | (c) — r4 섀도 플래그, 전향 평가로 판정 (REVIEW-07 §R4-8(2)) |
| 앵커 감쇠(유지 조건부) | 대회 VDOT × (1 − 0.14·max(0, 1 − CTL_now/CTL_race)) | 백테스트 중립, 비유지 n=2 | (a 가정: Daniels 휴식 표·Coyle 1984·Mujika 2000) — r4 섀도 플래그 |
| 품질: 코스 | GAP 속도 사용, 트레일·실내 제외 | – | (a/c) |
| 유형–거리 관련성 | 외삽분산(§4) | k_sd·ln 비 | (b) k 사후 |

- 기여도(UI)는 칼만 이득을 종류별로 분해한 합(대회·T·I·R·M·H·Tanda).
- 결합 결과의 80% 범위 = x ∓ 1.2816·√(P + σ대회²) — 한 번의 레이스 결과 예측이므로 대회 날 변동을 포함. 백테스트 적중 7/8(D-0), 6/8(D-28).
- 신뢰도 = P(|오차| ≤ 3%) = erf(0.03/(e_d·SD·√2)) — r3의 곱셈식(0.9×f…, 모두 휴리스틱)을 대체. 3%는 정의(표시 기준)이지 추정 상수가 아니다.

## 6. 개인 지구력 지수 k

- 사전 N(1.06, 0.03²): 1.06 (a) Riegel, SD 0.03 (c; 0.05로 바꾸면 D-0 1.68/D-28 1.90).
- 관측: 365일 전력 대회 중 거리 다른 **겹치지 않는 쌍**(시간 가까운 순으로 한 대회는 한 쌍에만). r3는 모든 쌍을 독립으로 넣어 과신(k_sd 0.016). 쌍 잡음 √(2σ대회² + q·간격) → k 단위로 변환 (b).
- 현재 k = 1.083 ± 0.021 (2026 봄 10K 45.7·46.2 대 하프 43.0·43.9) — 이 러너는 거리가 길어질수록 Daniels 기대보다 상대적으로 약하다 [사실].
