## 5. COACH — 대화 + 플랜 작업 목적지

Coach는 단순 Q&A가 아니라 목표 셋업·훈련 계획 수립/비교/수정(구 Plan "작업" 흡수)까지 하는
작업 목적지(destination)다. 계획을 "보는 것"(준수율·다음 세션 현황)은 `03a-today.md` L2에
남는다 — Coach는 "만드는 것"만 다룬다. 근거: `00-diagnostic-and-direction.md` §5.1, REVIEW-03.

플랜 생성 골격(정적 템플릿 비교)은 Phase 7b, ML 개인화 업그레이드는 Phase 7c에서 완성된다.
