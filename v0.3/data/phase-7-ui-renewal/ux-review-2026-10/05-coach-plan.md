- 기존 두 플랜 간 비교 화면(compare는 시나리오 선택만 존재): 해당 화면 없음
- 실제 DB/컨테이너 동작: 사본만 사용하는 제약
- Garmin 정리 UI: 외부 호출 금지 제약으로 호출하지 않음
- 타 사용자 플랜 접근 권한: 단일 사용자 앱
- ACWR 상세 시트, replan "직접 입력": 시간 부족
- 로딩 스켈레톤: 지연 라우트를 재현하지 못함
