## 처리한 미검증 항목 / 끝내 못한 항목과 사유

처리함
- 항목 1 오버레이: 드로어·동기화 시트·드릴 패널·해제 alertdialog 의 포커스 이동/트랩/Esc/뒤로가기/`?sheet=sync` 복원, 토스트 라이브 영역·5초 확인 (S-07~S-11).
- 항목 2 장애 주입: abort / 502 HTML 에서 Today, 활동 상세(요약·랩·스트림), 메트릭 상세, Data 개요, Coach 목록, 플랜, 활동 목록을 점검. 지연은 Today 에서 직접 진입·클라이언트 내비게이션 두 경우만 확인 (S-01~S-06).
- 항목 3 포커스·대비: 6개 화면 Tab×10 과 토큰 쌍 계산 (S-12~S-15).
- 항목 4 1280px: 5개 화면 DOM 측정, 가로 넘침 없음 (S-23).
- 항목 5 웰컴: 4단계 흐름, 입력 검증, 리다이렉트 조건을 별도 빈 DB 에서 재현 (S-19~S-22).
- 항목 6 활동 상세: 랩·스트림 빈 상태, 시간대 경계(S-16~S-18).

끝내 못한 항목
- 지연(hang) 시 메트릭 상세·Coach 목록·플랜: 라우트 패턴이 해당 호출에 맞지 않거나 SWR 캐시로 즉시 렌더되어 로딩 상태를 관측하지 못했다. 정확한 호출 경로를 확인해 재측정이 필요하다.
- 페이지네이션과 `from` 파라미터 복원, 합성 23:30 활동 삽입을 통한 자정 경계 재현: 활동 상세 쪽은 기존 DB 의 Strava 단독 행 하나로 갈음했고 합성 삽입은 하지 않았다.
- 1280px 이상 넓은 화면의 최대폭, 차트 라벨 실제 렌더 색의 개별 측정(토큰 값 계산으로 대체).
- ScopeSheet/EngineSheet 별도 Tab/Esc 점검, 비활성 버튼 대비 개별 측정.
- 장애 주입의 500 JSON 응답 중 서버 메시지 노출은 앞선 실행에서 "boom" 원문 노출을 확인했으나(중) 이 문서에는 ID 를 부여하지 않았다. 원문 메시지를 그대로 보이는 위치는 재확인 후 추가 필요.
