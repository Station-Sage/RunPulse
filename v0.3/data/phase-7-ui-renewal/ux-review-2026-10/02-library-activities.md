## 검증 완료 체크리스트

- 라이브러리 홈: 아카이브 히어로(총 거리·횟수 DB 일치), PB 6종, 1년 캘린더, 월별 거리, 최근 활동 5건, 소스 상태 — 375px 가로 넘침 없음 / A-29~A-31
- 활동 목록: 기간 칩 4종, 월 선택(최근 12개월), 종목 칩(합계 636 일치), 유형 칩, 거리 칩, 정렬 4종(date/distance/pace/load 동작 plausibility), 주간 요약 줄(5회 31.6km 3:15:20), 행 구성 — 375px 넘침 없음
- 활동 상세 요약: 러닝(17414: 거리·시간·페이스 API 일치, 랩 합 9298.05m=총거리), 수영(17425), 무데이터 러닝(17426), 근력(598), 걷기(603) / 404, 비정수 id
- 랩 탭(17414), 메트릭 탭(17414), 소스 비교 탭(17414), 스트림 탭(17414) 모두 375px 넘침 없음, 콘솔 오류 없음(404 응답 로그 제외)
- API 경계값: per_page, sort, from/to, q, 잘못된 id, 피드백 PUT/DELETE(rpe, pain, note, 비JSON)
- 접근성: Tab 순서, 라벨 누락, 랜드마크
- 문제 없음 확인: 요약 히어로 거리/시간(러닝), 랩 거리 합계, 종목 칩 합계, 아카이브 총계, 피드백 이중 제출 방지(저장 중 비활성), 피드백 메모 500자 제한, 존재하지 않는 id 404 화면

## 미검증 항목

- 랩 없는 활동의 랩 탭 빈 상태, 스트림 없는 활동의 스트림 탭 빈 상태(A-10)
- 목록 더보기/페이지네이션 동작과 `from` 복원(A-39, A-40)
- 사이클·야외 수영 등 다른 종목, GPS 없는 활동의 지도 영역
- 피드백 시트 UI의 서버 오류 메시지 표시, 메모 XSS 렌더(텍스트 바인딩 가정)
- `page.route` 지연·중단 주입(네트워크 실패/지연 상태), 색 대비 수치 계산
- KST 자정 경계 활동의 날짜 귀속, 지도 타일 로딩
