# Phase 7 UI — 목업 변천 로그 (Today 화면)

**문서 목적**: Today 화면 HTML 목업의 버전별 컨셉·디자인 원칙·변경 근거를
기록한다. 다중 AI 에이전트가 이 화면의 의도와 진화 맥락을 공유하기 위함이다.

**전제 문서**: `00`~`08` 설계서, `REVIEW-01`, `REVIEW-02`,
`08-mockup-and-implementation-plan.md`
**대상 화면**: Today (`mockups/today_black_*.html`)
**갱신 규칙**: 새 버전 목업을 만들 때마다 이 파일 맨 아래에 동일 형식으로 추가.
이전 버전 항목은 수정하지 않고 보존한다 (변천사 추적 목적).

---

## 공통 — 흔들리지 않는 기준 (모든 버전 공통)

이 기준은 RunPulse 앱 철학(`future_vision.md`, `architecture.md`)과 8개 설계
원칙(`01-design-principles.md`)에서 나온다. 버전이 바뀌어도 유지된다.

- **P5 Quiet Data**: 무채색 베이스 + 시맨틱 색만 의미 전달. 글래스모피즘·
  네온·장식 그라데이션·의미 없는 모션 금지. 데이터가 주인공.
- **토큰 SSOT**: 모든 색·간격·폰트는 `:root` 변수만 참조. hex/px 하드코딩
  금지. 목업이 곧 토큰 실험장이며, 안정화되면 `08-design-system.md`로 추출.
- **데이터 형태 일치**: 더미 데이터 구조를 `04-component-catalog.md` props
  인터페이스에 맞춘다 (API 교체 시 마찰 최소화).
- **타이포 체계**: 본문 Inter, 수치 JetBrains Mono.
- **다크 모드 우선**: 다크 기준으로 만들고 토큰으로 라이트 파생.

## v1 — `today_black_01.html`

**한 줄 컨셉**: 표준 대시보드 — 섹션별 카드 나열.

**구성**
- QuickInput(피로도 10단계 + 통증) → MetricCell ×3 (UTRS/CIRS/TSB) →
  RecommendationCard + EvidenceQuote → 예정 세션(P7) → 최근 활동.
- MetricCell 클릭 시 우측 MetricBreakdown 패널 (formula_v1·재계산·diff).

**적용 원칙**: P1(근거 칩), P2(드릴다운 패널), P3(provider 배지),
P5(시맨틱 색), P6(QuickInput 상시 노출), P7(상태 기반 세션 조정).

**의도**: 8원칙·7컴포넌트를 한 화면에서 최대한 검증.

**받은 피드백**
1. 깔끔하다.
2. 모바일에서 3열 고정 그리드(MetricCell) 때문에 가로 스크롤 발생.
3. "최고의/혁신적" 느낌이 없다. 평범한 흔한 앱 같다.

**한계 진단**: 구성요소를 잘 정리했을 뿐, RunPulse 정체성(소스 통합·투명한
드릴다운·근거 기반 판단)이 시각 언어로 드러나지 않음. = 일반 대시보드.

## v2 — `today_black_02.html`

**한 줄 컨셉**: 판단 우선 + 소스 통합 가시화 (색·구성 리디자인).

**v1 대비 변경**
- 모바일 가로 스크롤 해결: `.subs` 그리드를 560px 이하 1열로, 네비 숨김.
- 상단 **fusion 스트립** 신설: 4-source가 하나로 합쳐지는 흐름을 상시 노출
  (RunPulse 정체성 = 소스 통합).
- 핵심 지표를 카드 나열 대신 **히어로**(도넛 링 UTRS 72 + "회복 우선" 판단)
  로 통합 → "그래서 오늘 뭘 하나"를 먼저 답함.
- EvidenceQuote 칩에 provider 색 점 추가.
- 히어로 배경·탑바에 미세 그라데이션/블러 (※ P5 충돌 소지 — 실험적).

**적용 원칙**: v1 + 소스 통합 시각화 강화.

**받은 피드백**
- 보여주는 콘텐츠가 부실하다.
- "자세히 보기"의 formula_v1 표기가 너무 작아 클릭 가능해 보이지 않는다.
- 여전히 "기존 것의 색·구성만 바꾼" 수준. 근본적으로 다시 생각할 것.

**한계 진단**: 시각적 리디자인에 머물렀고, 화면의 *동작 모델*은 v1과 동일
(여전히 "보여주기" 중심). 드릴다운이 부가 기능에 머물러 투명성이 체감되지 않음.

## v3 — `today_black_03.html`

**한 줄 컨셉**: **근거 계층(Evidence Hierarchy)** — Today는 대시보드가 아니라
"오늘의 판단을 둘러싼 근거를 층층이 펼쳐 파고드는" 화면.

**핵심 발상 전환 (v1·v2와 근본적으로 다른 점)**
- 화면 중심 동작을 "보여주기"에서 **"파고들기(drill-down)"**로 이동.
- 정보 흐름: **판단 → 판단을 떠받치는 지표 → 지표의 구성요소 → 원본**.
  어디든 클릭하면 다음 층으로 내려가고, drill-down이 화면의 중심 동작이 됨.

**v2 대비 변경**
- 히어로: 도넛 링(Readiness 72) + "회복 우선 · E2" 판단 + 설명. 그 아래
  판단을 떠받치는 3지표(UTRS/ACWR/TSB)를 **무슨 데이터로 합성됐는지 부제**와
  변화량(▲▼)까지 달아 나열. 각 행에 `›` 화살표 + 호버 이동 → "들어가는 곳"
  임을 명시.
- AI 브리핑: 근거를 본문에 **인라인으로 박음** (ACWR 1.34 / HRV 58ms /
  피로도 7가 문장 안에서 클릭 가능한 칩).
- **드릴 패널 전면 재설계** — formula_v1을 작은 태그가 아니라 **"출처 & 계산"
  명시 블록**으로: 공식·신뢰도·마지막 재계산 시각·이전값 diff·구성 출처를
  또렷이 표시 (AO-1 의도 시각화). 구성요소 트리는 각 항목이 또 클릭되어 더
  파고들 수 있고("클릭하여 더 파고들기"), 같은 지표의 provider 비교 +
  대표값 근거(dedup.py 정적 순서)까지 포함 (AO-3).
- 콘텐츠 밀도 대폭 상향: 활동마다 HR·TSS·존 분포·VO₂·decoupling + 이 활동을
  함께 기록한 멀티소스 배지.
- 미세 그라데이션 제거 → 플랫 (P5 정합).

**적용 원칙**: P1~P3 강하게(근거·드릴다운·투명성이 화면 중심), P5, P6, P7 +
AO-1(메트릭 버전/재계산 표현), AO-3(is_primary 정적 근거).

**상태**: 방향성 검토 중. 확정 시 이 "근거 계층" 언어를 Activity 상세·
Provider 매트릭스 등 다른 화면에도 일관 적용 예정.
