# 결정 필요 항목 통합 표 (2026-10 v2 점검 설계 10건)

- 각 설계서 "결정 필요" 섹션의 항목을 그대로 모은 것이다. **모두 미결정**이며, 선택지·장단점은 원문(요약 없음)이다. 결정 ID 는 `설계서코드-순번`(설계서 내 D 번호 순서와 같음).
- 설계서 위치: `patterns/`(횡단 패턴 8건: SRV·FRS·NRA·OVL·ERR·SEC·TZ·A11Y), `bundles/`(HSR·PLN·ADJ·NEW).
- 총 136건 (결정 105건 / 부분 결정 2건 / 미결정 29건).

## 설계서 간 연관 결정(설계서에 명시된 것만)

| 함께 정해야 하는 결정 | 이유 |
|---|---|
| SEC-5 ↔ SRV-1 | Origin 헤더 없는 요청 처리와 Referrer-Policy 값이 서로 영향(보안 헤더 설계서 D5 가 Origin 검증 D1 과 함께 결정하라고 명시) |
| HSR-1 ↔ PLN-6 ↔ PLN-10 | 거리 비율 상한(1.6)은 HSR 결정 1 과 PLN 에서 단일 결정으로 묶음. 판정 우선순위(D6)·`_effective` 순위(D10) 도 같은 매칭·라벨 로직 |
| ERR-7 ↔ OVL | E-23(DemoBanner Esc)을 오류·재시도에서 빼고 오버레이 설계로 일원화할지 |
