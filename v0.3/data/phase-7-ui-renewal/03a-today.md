## 1. TODAY — 관여 기반 관문 (L0~L3)

Today는 하단 3탭의 첫 번째이자 유일한 진입점이다. 세로 스크롤 = 관여 깊이. 구 Story(내러티브)는
L2로, 구 Plan의 "보기"(준수율·다음 세션)도 L2로 흡수됐다 — Plan의 "작업"(수립·수정)은
`03e-coach.md`로 이동했다. 근거: `00-diagnostic-and-direction.md` §5.1, REVIEW-03.

**L2는 Phase 7b에서 완성형으로 구현된다 — Phase 7a는 텍스트 스텁(준수율 한 줄, 다음 세션
한 줄)만 노출한다.** 근거: 비전 문서(`phase-7(preview).md`) §6의 그룹1(데일리 브리핑)/그룹2
(내러티브 보고서) 우선순위 분리. 상세: `00-diagnostic-and-direction.md` §4.1.
