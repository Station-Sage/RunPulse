### R4-2. 채택안 (r4)

```
관측 (as_of 이전 365일):
  대회  y = VDOT(15℃ 등가, 개인 heat_model)            분산 1.0²   고유거리 = 대회 거리
  세트  y = VO2(v_work) / %VO2max(t_eq(ρ, 반복))        분산 1.75²×품질배율   고유거리 = v·t_eq  (기온 정규화 안 함)

목표 거리 d 마다:  y_d = VDOT(d, Daniels(y,d)·(d/고유거리)^(k−1.06)),  분산 += (k_sd·|ln(d/고유거리)| / e_d)²
  (d가 최근 12주 최장 러닝보다 길면 k_sd² += 0.03²·(ln(d/최장)/ln(d/고유거리))² — 롱런 외삽)
칼만(랜덤워크 q=0.01/일) → x_d, P_d ;  예측 = Daniels(x_d, d) (15℃),  예측 SD = √(P_d + 1.0²)
마라톤: ln T = 역분산 결합[칼만, Tanda(주간 km·평균 페이스, SD 4%)] (주 15km 미만이면 Tanda 제외)
80% 범위 = x ∓ 1.2816·SD,  신뢰도 = P(|오차| ≤ 3%) = erf(0.03 / (e_d·SD·√2)),  기여도 = 칼만 이득 분해(종류별)
k = N(1.06, 0.03²) 사전 + 365일 전력 대회의 겹치지 않는 쌍(시간 간격 가까운 순), 쌍 잡음 = √(2·1.0² + q·간격)
```

**(2) 대회·세트 비대칭, 유지 조건부 앵커** [사실+판단]

- 순환성 점검: r4 세트 VDOT는 Daniels 정의(T = 60분 레이스, I = %VO2max 1.0)로 환산하고 대회에 맞춘 편향 항이 **없다**(r3 W의 "최근접 대회 대비 편향 0" 보정 같은 것 없음). 다만 σ세트·대비 임계 1.18·보간 앵커는 대회가 포함된 전 기간을 보고 정했다(in-sample). 칼만은 세트를 x의 불편 관측으로 다루므로 세트의 하한 편향(REVIEW-09 2상태 모형 τ≈1.0 VDOT, 비유의)은 x를 대회 수준 아래로 끌어내린다. 그래서 r4가 r3보다 느리다.
- 비대칭 변형: 관측이 현재 상태보다 **낮을 때만** 분산 ×4. 대회는 "상한에 가까운 증거"라서 느린 대회를 나쁜 날일 수 있다고 보고 약하게 반영한다. 세트는 "하한 증거"라서 느린 세트를 약하게 반영한다(×4는 (c)).
- 유지 조건부 앵커: 대회 VDOT × (1 − α·max(0, 1 − CTL(기준일)/CTL(대회일)))이고 α = 0.14다. α 도출은 [가정 — Daniels 원표 대조 전]이다. Daniels의 완전 휴식 표(4주 휴식 ≈ VDOT 93%)에서 4주 무훈련 시 CTL(42일 EWMA)이 51%로 떨어지므로 0.07/0.49 ≈ 0.14로 잡았다. 근거 문헌은 둘이다. Coyle 1984는 완전 중단 2~4주에 VO2max −4~−14%다. Mujika & Padilla 2000은 강도를 유지하면 볼륨을 60~70% 줄여도 수 주~15주까지 유지된다고 한다. 즉 시간이 아니라 **부하 유지**가 감쇠를 결정한다. CTL이 오르면(유지·향상) 보정 0이다. 향상은 세트·H가 맡는다.
- 유지/비유지 분리: 대상 대회일 CTL / 직전 전력 대회일 CTL ≥ 0.9를 "유지"로 본다. 유지 5건, 비유지 2건(2025-11-09 0.63, 2026-04-11 0.83), 첫 대회 1건은 제외다.

### 2-7. 심박-속도 관계와 기온 효과 (r2 재평가)

> **r3**: 기기 온도 대신 외기(Open-Meteo)로 다시 적합했다 — 15℃ 이상 −0.62%/℃, 5℃ 이하 −0.84%/℃, R² 0.42. 개인 `heat_model`은 이를 기본값으로 수축 추정(현재 −0.72 / −0.76). 겨울 잔차는 외기로도 남는다(1~2월 −3.9·−7.4%).

| T0 | c (1℃당 속도 변화) | R² |
|---|---|---|
| 10℃ | −0.45% | 0.41 |
| **15℃** | **−0.59%** | **0.43** |
| 20℃ | −0.97% | 0.45 |

  기온 없는 모델의 R²는 0.31이다. **채택은 T0=15℃, −0.59%/℃**다.
  - 문헌 대조 [가정: 원문 수치 확인 필요]: Ely 등(2007) 마라톤 기록 분석에서 WBGT가 약 5℃에서 25℃로 오르면 중상위권 러너 기록이 수 % 느려진다. 이 러너의 계수(10℃ 차에 약 6%)는 **기기 온도(손목, 외기보다 높게 나옴)** 기준이라 직접 비교할 수는 없다.

- **레이스 당일 편향(기온 보정 후)**: 직전 90일 모델에 레이스 평균 HR과 레이스 기온을 넣었을 때, 실제 속도가 모델보다 **평균 +5.5%, SD 5.7%**(n=8, 범위 −2.8~+16.7%) 빨랐다. 보정 전(+7.8%)보다 줄었지만 SD가 커서 **고정 보정계수로 쓰면 개별 예측 오차가 ±7% 수준**이 된다 → 단독 신호로는 부적합하다.
- **LTHR 앵커링**: 같은 곡선에서 LTHR 177의 속도를 "60분 레이스 속도"로 보고 Daniels VDOT를 계산한 H 신호는 레이스 9건에서 D-0 MAE 4.2%(편향 +1.5%), D-28 MAE 4.7%다. 앵커가 없을 때의 **폴백으로는 쓸 만한** 수준이다.

- **대리 타깃 롤링**(`34_rolling_temp.py`, `36_adopted_r3.py`): r2와 같은 타깃·분할. 모든 성과 신호를 15℃ 등가로 정규화한 뒤 타깃 당일 외기로 환원했다. 세그먼트 bout W와 기온 정규화 W는 여름 bout를 과대평가해 채택하지 않았다. 36의 "블록 자격 T0(속도)" 변형은 대회 D-0 1.8%, (b)/(c) 2.8%(2025-09-14 더운 하프 +8.8% — 학습 구간 적합 더위 계수 −0.96%/℃가 과보정). **실제 구현은 개인 계수를 기본값(−0.62)으로 수축**해 같은 대회가 −0.3%로 맞는다(§0-3 (1)).
- **절제**(`38_calc_ablation.py`)는 명세 코드 그대로(샌드박스)를 실DB 사본에서 대회일별로 다시 계산했다. 날짜별 `hr_profile`·`heat_model`을 그 날짜 이전 데이터로만 다시 만든다(누수 없음). 단 (b)는 기기 LTHR 177(2026-05 측정값)을 과거 전체에 적용해서 누수가 있다.
- **3종 경로 결론**: T2(기기 참조)가 있어도 (c)보다 낫다는 근거는 없다. T1(HR만)으로 충분하고, T0(GPS·시간)도 D-0 1.7%로 쓸 만하다. 대신 T0는 대회 전력 여부를 HR로 판정할 수 없으므로 대회 확인 입력(P7-PRED-53·73)이 중요해진다.

### 4-4. 5K와 신뢰도 (Q9)

- 5K = 결합 VDOT의 Daniels 환산(+개인 k). 90일 5K best effort는 **중앙값에 넣지 않고** 일치도 신호로만 쓴다(구간 기록·기온 미정규화라 하한 성격).
- 신뢰도 = 0.9 × f(앵커 최근성: 8주 1.0 → 52주 0.5) × f(신호 간 차이: 3% 1.0 → 10% 0.6) × f(신호 수: 1개 0.7, 2개 0.9, 3개 이상 1.0) × f(거리 외삽: 1배 1.0 → 4.2배 0.75) × f(마라톤 모델 차: 3% 1.0 → 12% 0.5). 상한 없음. 이유 문자열을 함께 저장.
- 범위: `중앙값 × (1 ± 1.2816·0.035·(1 + 0.5(1 − conf)))`, 느린 쪽 가산(주 15km 미만 마라톤 +3%p, 계획 이행률 <70% +1%p).

### 4-5. 마라톤

r2 §4-6과 같다(Daniels·Tanda 기하평균, 손계수 없음). 추가: 주 15km 미만이면 Tanda 적용 범위 밖으로 보고 Daniels만 + 신뢰도 ×0.8 + 느린 쪽 +3%p [가정]. EF·디커플링·HR 드리프트는 마라톤 검증 표본이 없어 범위·설명에만 쓴다.
