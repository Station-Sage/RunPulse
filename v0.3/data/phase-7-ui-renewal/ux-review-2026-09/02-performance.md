# UX 리뷰 2026-09 — 02. 성능 측정

**측정일**: 2026-09-27 · 실서비스 `localhost:80`(OCI 호스트 내부, 네트워크 왕복 거의 0 — 실제 사용자는 Cloudflare 경유라 **여기 수치 + 네트워크 지연**을 겪는다)
**도구**: Playwright Chromium headless, 페이지마다 새 컨텍스트(콜드 캐시). 원자료 `raw/tour.json`, `raw/interact-{desktop,mobile}.json`, 스크립트 `raw/tour.mjs`, `raw/interact.mjs`.
**기준**: `00-vision-criteria.md` §4 (초기 로딩 ≤1.5s 좋음/≤2.5s 허용, 전환 ≤300ms/≤1s, 클릭 피드백 ≤100ms/≤200ms, API ≤200ms/≤800ms)

## 1. 핵심 결론

1. **서버가 요청을 직렬 처리한다.** gunicorn이 `--workers` 미지정(기본 1 sync worker, 스레드 없음) + `--reload`로 뜬다(`Dockerfile:21`). 화면이 API를 `Promise.all`로 병렬 호출해도 서버에서 줄을 서므로, 개별로는 10~20ms인 API가 화면 안에서는 500~1,100ms로 측정된다. (예: `race-hub` 단독 22ms → Today 안에서 581ms, `providers/coverage` 단독 11ms → Library 안에서 1,099ms)
2. **느린 API 두 개가 체감 속도를 결정한다.** `/api/v1/library/metrics` 단독 **776ms**(Library 홈·메트릭 브라우저), `/api/v1/today/narrative` 단독 **413ms**(Today).
3. **로딩 중 피드백이 전혀 없다.** 모든 라우트의 `+page.ts` `load()`가 모든 API를 기다린 뒤에야 화면을 그린다(`frontend/src/routes/today/+page.ts:21`, `library/+page.ts:19`). `navigating` 스토어·스켈레톤·진행바 사용 0건(grep). 그래서 **Today→Library 탭 클릭 후 1.2~1.3초 동안 이전 화면이 그대로 멈춰 있다**(클릭 피드백 없음, INP 기준 "나쁨").
4. **활동 상세 API가 650KB.** `/api/v1/library/activities/:id` 응답에 스트림 전체가 들어 있어 요약·랩·메트릭 서브탭마다 같은 650KB를 다시 받는다(스트림 탭은 630KB 추가 → 1.28MB). 로컬에선 50ms지만 모바일 LTE에선 서브탭 전환마다 수백 ms~초 단위.
5. **v1은 서버 렌더가 느리다.** TTFB 0.7~1.3s, FCP 1.6~2.2s. 루트 진입이 v1이므로 **첫인상 로딩이 2.2초**.
6. v2의 가벼운 화면(Coach·계획·세션·메트릭 상세)은 FCP 0.3~0.5s, 클릭→전환 80~200ms로 **양호**.

## 5. 개선 제안 (우선순위)

| # | 심각도 | 제안 | 근거 |
|---|---|---|---|
| P-1 | 치명 | gunicorn `--workers 2~4 --threads 4` (또는 gthread) 및 운영에서 `--reload` 제거 | 직렬 처리로 화면당 +0.5~1.0s |
| P-2 | 중요 | 라우트 전환 즉시 피드백: 상단 진행바(`$navigating`) + 블록 단위 스켈레톤, 핵심 데이터 먼저 렌더하고 부가 데이터(narrative·trend·coverage)는 스트리밍/지연 로드 | 탭 클릭 후 1.3s 무반응 |
| P-3 | 중요 | `/library/metrics` 776ms, `/today/narrative` 413ms 원인 분석·캐시(일 단위 계산값은 사전 계산/ETag) | 느린 API 2개가 체감 속도 결정 |
| P-4 | 중요 | 활동 상세 API에서 스트림 분리(요약용 다운샘플 폴리라인만), 서브탭 간 데이터 공유(레이아웃 load) | 650KB × 서브탭 수 |
| P-5 | 개선 | 탭 재방문 캐시(stale-while-revalidate) | 재방문도 1.2s |
| P-6 | 개선 | 루트 진입을 v2로 전환하면 첫인상 로딩 2.2s → 1.2s | v1 TTFB 0.9s |
